# APQ Cleaning Service

Mobile-first staff timesheet, scheduling, SMS reminder and Xero invoicing web app for APQ Cleaning Service (Northern Beaches, Sydney).

**Stack:** Laravel 12 · PHP 8.4 · MariaDB · Livewire 3 · Tailwind v4 · cPanel hosting
